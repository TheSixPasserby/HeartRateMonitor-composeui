# 更新日志

## v4.9.6

- 心率记录与导出 CSV 统一为每秒 1 行：设备广播间隔大于 1 秒时自动以前值按秒补齐（超过 10 秒的断开缺口不伪造数据）
- 手动开始记录时，实时折线图清空并从 0 秒重新绘制（最高/最低统计同步重置）
- 内置测试数据调整为 2 分钟（用于快速验证导出）

## v4.9.5

- 心率历史记录新增三档模式：手动 / 自动 / 不记录（默认手动）
- 首页顶栏新增记录按钮：点击开始记录并显示计时，再次点击停止并保存到历史
- 手动停止时丢弃无任何记录的空会话

## v4.9.4

- 关于页迁移至本仓库（检查更新接入 GitHub Release），新增原作者鸣谢入口
